# Chronos Art 🏛️→🖼️→💻

**A linha do tempo de toda a história da arte e do design — da pintura rupestre à arte com IA.**

Navegue por eras, movimentos, regiões e obras, com contexto histórico, artistas e técnicas.

## Status
Projeto completo e em uso. Dados em `src/data/` (eras, movimentos, obras por meio, contextos regionais). A checagem contínua de fatos está no **[PLANO.md](PLANO.md)**.

## Rodar
```bash
npm install
npm run dev   # http://localhost:3000
```
